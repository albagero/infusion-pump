# PROJECT OVERVIEW

You are an expert Frontend Engineer, UI/UX Designer, Motion Designer, and Medical Simulation Developer.



This is NOT a slideshow.

It is an immersive storytelling website combined with an educational infusion pump simulator.

The audience should feel like they are exploring a modern software product rather than viewing slides.


------------------------------------------------------------

PROJECT GOALS


• Create an engaging interactive presentation.
• Teach infusion pump concepts.
• Allow users to practice using a simulated pump.
• Include animations throughout.
• Feel like a premium Apple product presentation.
• Be responsive.
• Deploy easily to GitHub Pages.
